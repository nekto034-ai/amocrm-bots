- Провайдер: Timeweb Cloud (осознанный выбор — дешевле Yandex/VK Cloud ~в 2 раза при сопоставимых характеристиках для старта; можно вырасти позже).

- API-токен Timeweb Cloud выпущен Артёмом и передан в чат (не хранится в этом файле/репозитории — секреты сюда не кладём).

## Важный технический момент

У сессий есть "окружения" (environment) с настройкой сетевого доступа (Trusted/Full). Если какой-то внешний API вдруг недоступен (соединение рвётся/отклоняется) — в первую очередь проверить настройки окружения сессии, а не считать это багом кода. Основное рабочее окружение для этого проекта — с полным доступом ("Full"/"amoCRM полный доступ").
