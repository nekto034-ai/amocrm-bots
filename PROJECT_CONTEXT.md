- Целевая конфигурация: Ubuntu 24.04 LTS, тариф уровня Cloud MSK 40 (~2 CPU, ~2 ГБ RAM, ~40 ГБ NVMe), регион Москва, ориентир ~880 ₽/мес.
- Артём зарегистрировался на timeweb.cloud, выпустил API-токен (с настройками: удаление по API без кода в Телеграме — включено; скрывать пароли — выключено; ограниченные права — выключено, т.е. токен полного доступа). **Токен уже был отправлен Артёмом отдельным сообщением в эту сессию** (в чате, не в этом файле — секреты в файл намеренно не записаны).
- **Баланс аккаунта Timeweb Cloud сейчас 0 ₽.** Артём пока сознательно не пополнял баланс — просил сначала проверить, что токен рабочий и посмотреть доступные тарифы, оплату отложил на потом.
- Следующий шаг, когда сессия это увидит: проверить токен безопасным read-only запросом (например, баланс/тарифы через `https://api.timeweb.cloud/api/v1/...`), показать Артёму результат. Реальное создание сервера — только после того, как Артём пополнит баланс и явно попросит создать.

## Технический момент, который важно знать

У сессий Claude Code на этой платформе есть понятие "окружения" (environment) с настройкой сетевого доступа (Trusted / Full). Один из прошлых чатов Артёма упёрся в сетевую блокировку (Trusted-окружение не пускало наружу к amoCRM/Timeweb) — отсюда и появился этот, параллельный чат с окружением "amoCRM полный доступ" (Full). Если в будущем какой-то внешний API вдруг недоступен — это тоже может быть причиной, стоит проверить настройки окружения, а не считать это ошибкой кода.
